Palindrome Program in Python

Problem Description

Write a Python program to check whether a given number is a palindrome.

What is Palindrome?

A palindrome number is one that remains the same when reversed. Example: 121, 454, 888.

Method 1: Using While Loop


n = int(input("Enter number:"))
temp = n
rev = 0
while n > 0:
    dig = n % 10
    rev = rev * 10 + dig
    n = n // 10
if temp == rev:
    print("The number is a palindrome!")
else:
    print("The number isn't a palindrome!")

Explanation: Reverses the number using digit extraction and compares with original.

Method 2: Using Built-in Function


def is_palindrome(n):
    return str(n) == ''.join(reversed(str(n)))

n = int(input("Enter number:"))
if is_palindrome(n):
    print("The number is a palindrome!")
else:
    print("The number is not a palindrome.")

Explanation: Converts number to string, reverses it using built-in methods.

Method 3: Using Recursion


def is_palindrome(n, temp, rev=0):
    if n == 0:
        return "Palindrome!" if temp == rev else "Not Palindrome!"
    dig = n % 10
    rev = rev * 10 + dig
    return is_palindrome(n // 10, temp, rev)

n = int(input("Enter number:"))
print(is_palindrome(n, n))

Explanation: Uses recursion to reverse number and check.

Method 4: Using String Slicing


def is_palindrome(n):
    return str(n) == str(n)[::-1]

n = int(input("Enter number:"))
if is_palindrome(n):
    print("Palindrome!")
else:
    print("Not Palindrome!")

Explanation: Converts to string and checks with reverse slice.

Time & Space Complexity

  • While Loop: Time - O(log n), Space - O(1)
  • Built-in: Time - O(n), Space - O(1)
  • Recursion: Time - O(log n), Space - O(log n)
  • Slicing: Time - O(n), Space - O(n)
