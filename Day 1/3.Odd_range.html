🔢 Python Program to Print All Odd Numbers in a Range

📘 Problem Description

This program takes a lower and upper limit as input and prints all odd numbers in that range.

💡 Problem Solution

  • Take input for lower and upper limits.
  • Use a for loop to iterate from lower to upper limit.
  • Check if the number is odd using i % 2 != 0.
  • If odd, print it.

🧠 Python Code

lower = int(input("Enter the lower limit for the range: "))
upper = int(input("Enter the upper limit for the range: "))
for i in range(lower, upper + 1):
    if i % 2 != 0:
        print(i)

📖 Program Explanation

  • The user enters two values: lower and upper limits.
  • The loop runs from lower to upper.
  • Each number is checked using the condition i % 2 != 0.
  • If true, it's printed as an odd number.

Time Complexity: O(n)

Space Complexity: O(1)
