Python Program: Sum of Digits using Recursion

This program takes a number as input and uses a recursive function to calculate the sum of its digits.

  1. Define a recursive function that extracts each digit of the number.
  2. Store digits in a list using recursion.
  3. Calculate the sum of the list after recursion ends.
  4. Print the final result.

Python Code:

l = []
def sum_digits(b):
    if b == 0:
        return l
    dig = b % 10
    l.append(dig)
    sum_digits(b // 10)

n = int(input("Enter a number: "))
sum_digits(n)
print(sum(l))

1. The function sum_digits() uses recursion to extract digits from the number.
2. Each digit is obtained using % 10 and added to list l.
3. The function calls itself with b // 10 until b becomes 0.
4. After recursion ends, the sum of the list l is calculated and printed.
