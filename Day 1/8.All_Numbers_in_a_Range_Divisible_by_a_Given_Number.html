Python Program: Range Numbers Divisible by a Given Number

The program takes a lower and upper range and a number, then prints all numbers in the range that are divisible by the given number.

  1. Take lower and upper range input from the user.
  2. Take a number from the user to divide by.
  3. Use a loop to iterate through the range.
  4. Print numbers where remainder of number divided by given number is 0.

Python Code:

lower = int(input("Enter lower range limit: "))
upper = int(input("Enter upper range limit: "))
n = int(input("Enter the number to be divided by: "))

for i in range(lower, upper + 1):
    if i % n == 0:
        print(i)

1. User enters a lower limit, upper limit, and a divisor.
2. A loop runs from the lower limit to upper limit.
3. For each number in the loop, we check i % n == 0.
4. If true, the number is divisible and printed to the output.
