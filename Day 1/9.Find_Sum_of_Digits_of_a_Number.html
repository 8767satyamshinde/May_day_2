Python Program: Sum of Digits in a Number

This program takes a number as input and calculates the sum of its digits using a while loop.

  1. Input a number from the user.
  2. Initialize a total sum variable as 0.
  3. Use a while loop to extract digits and add them to the sum.
  4. Repeat until the number becomes 0.
  5. Print the total sum.

Python Code:

n = int(input("Enter a number: "))
tot = 0
while n > 0:
    dig = n % 10
    tot = tot + dig
    n = n // 10
print("The total sum of digits is:", tot)

1. The user inputs an integer.
2. The loop gets the last digit using n % 10.
3. Adds it to the total sum variable.
4. Then removes the last digit using integer division n = n // 10.
5. Repeats until n becomes 0.
6. The final sum is printed.

Case 1:

Enter a number: 1892
The total sum of digits is: 20

Case 2:

Enter a number: 157
The total sum of digits is: 13
