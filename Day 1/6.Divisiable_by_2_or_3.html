Python Program to Print All Integers that Aren’t Divisible by Either 2 or 3

This program prints all integers from 1 to 50 that are not divisible by either 2 or 3.

  1. Use a for loop from 0 to 50.
  2. Use if condition to check i % 2 != 0 and i % 3 != 0.
  3. If true, print the number.

Python Program:

for i in range(0, 51):
    if(i % 2 != 0 and i % 3 != 0):
        print(i)
