🔢 Python Program to Check Whether a Number is Positive or Negative

📘 Problem Description

This program takes a number as input and checks whether it is positive or negative.

💡 Problem Solution

  • Take the value of the number as input.
  • Use an if statement to check whether the number is greater than 0.
  • If yes, it's positive; otherwise, it's negative.

🧠 Python Code

n = int(input("Enter number: "))
if n > 0:
    print("Number is positive")
else:
    print("Number is negative")

Explanation:

  • User enters a number, which is stored in variable n.
  • if n > 0: number is positive.
  • Else: number is negative (note: 0 will also be treated as negative in this version).

Time Complexity: O(1)

Space Complexity: O(1)

🧪 Runtime Test Cases

Case 1:

Enter number: 45
Number is positive

Case 2:

Enter number: -30
Number is negative
