🧮 Python Program to Check Odd or Even (Multiple Methods)

🧠 Using Modulus Operator

This method checks if a number is divisible by 2 using %.

n = int(input("Enter a number: "))
if n % 2 == 0:
    print(n, "is an even number.")
else:
    print(n, "is an odd number.")

Explanation: The modulus operator (%) returns the remainder. If it's 0 when divided by 2, it's even; otherwise, it's odd.

Time Complexity: O(1)

Space Complexity: O(1)

🧠 Using Bitwise Operator

This method checks the least significant bit using &.

n = int(input("Enter a number: "))
if n & 1:
    print(n, "is an odd number.")
else:
    print(n, "is an even number.")

Explanation: The bitwise AND with 1 checks the last binary digit. If it's 1, the number is odd; if 0, it's even.

Time Complexity: O(1)

Space Complexity: O(1)

🧠 Using Recursion

This method subtracts 2 recursively until it reaches 0 (even) or 1 (odd).

def check(n):
    if n < 2:
        return (n % 2 == 0)
    return check(n - 2)

n = int(input("Enter number: "))
if check(n):
    print("Number is even!")
else:
    print("Number is odd!")

Explanation: Recursion subtracts 2 from the number repeatedly. Even if it reaches 0, odd if 1.

Time Complexity: O(n)

Space Complexity: O(n) due to call stack.

🧠 Using Lambda Function

This method uses a short inline lambda function.

check_number = lambda num: "even" if num % 2 == 0 else "odd"

number = int(input("Enter a number: "))
result = check_number(number)

print(number, "is an", result, "number.")

Explanation: A lambda is a short anonymous function. This one returns "even" or "odd" based on % 2.

Time Complexity: O(1)

Space Complexity: O(1)
