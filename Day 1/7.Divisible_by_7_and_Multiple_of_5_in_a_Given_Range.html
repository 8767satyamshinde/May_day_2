Python Program: Divisible by 7 and Multiple of 5

The program takes an upper and lower range from the user and finds all numbers within that range which are divisible by 7 and are also multiples of 5.

  1. Take input for upper and lower range.
  2. Use a loop to iterate through numbers in the given range.
  3. Check if each number is divisible by both 7 and 5.
  4. If so, print that number.

Python Code:

lower = int(input("Enter the lower range: "))
upper = int(input("Enter the upper range: "))

for i in range(lower, upper + 1):
    if i % 7 == 0 and i % 5 == 0:
        print(i)

1. The user inputs two values: a lower limit and an upper limit.
2. A loop runs from the lower limit to the upper limit.
3. Within the loop, the program checks if the number is divisible by both 5 and 7 using the condition i % 5 == 0 and i % 7 == 0.
4. If the condition is true, the number is printed.
